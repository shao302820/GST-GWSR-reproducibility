`heat_flow_stations.csv` is the exact 1,024-row table used by the current recorded experiments. The source products and processing scripts are included. `scripts/prepare_dataset.py` documents and reruns the deterministic construction path.

The table schema is `lon`, `lat`, `heat_flow`, `topo`, `bouguer`, `sediment`, `moho`, `lab`, `cpd`, `lithos_km`, and `volcano`.
